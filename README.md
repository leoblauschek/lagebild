# Lagebild

Privates Nachrichten-Dashboard mit einem täglichen Abendbriefing zu künstlicher Intelligenz, deutscher und europäischer Politik sowie weltpolitischen Entwicklungen.

Die veröffentlichte Seite liegt vollständig in `dist/index.html`. Jede Meldung enthält eine kurze Einordnung und einen Link zur Originalquelle. Social-Media-Signale werden getrennt von verifizierten Nachrichten gekennzeichnet.
